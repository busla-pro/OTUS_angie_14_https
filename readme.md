# ДЗ урока № 14 — Настройка HTTPS для веб-сервисов

ДЗ будем делать используя WordPress в Docker из урока 10:

Набор файлов для запуска в каталоге `wp`.

Секреты определены через файл `.env`, который не опубликован в репозитории. Ожидаемое содержимое файла:
```
MYSQL_ROOT_PASSWORD=
MYSQL_USER=
MYSQL_PASSWORD=
```

Настраивать будем на доменное имя `otus-angie-14.s7h.ru`

1. На хосте установим `certbot` и получим сертификат от Let's Encrypt.
2. В `docker-compose.yml` добавим проброс портов и каталогов сертификата с ключом.
3. В `http_angie.conf` добавим биндинг порта и пути к сертификату и ключу.
4. Добавим директивы для серверного и клиентского кэширования tls-сессий.
5. Выделим http (порт 80) в отдельную директиву `ыукмук` и пропишем там только переадресацию на https
6. Добавим заголовок HSTS - туда разумно вписывать значительный срок, но в наших учебных целях ограничимся часом, что не задаваться вопросом зачистки браузера, если понадобится чистый http.
7. Включим поддержку http2 с дэфолтными ограничением количества потоков и размером чанка.
