# ДЗ урока № 10 — Оптимизация производительности веб-сервисов

ДЗ будем делать используя WordPress в Docker из урока 6:

Набор файлов для запуска в каталоге `wp`.

Секреты определены через файл .env, который не опубликован в репозитории. Ожидаемое содержимое файла:
```
MYSQL_ROOT_PASSWORD=
MYSQL_USER=
MYSQL_PASSWORD=
```

В конфиге angie (`angie-conf/http_angie.conf`):
* разделим location по регулярке типично статичных файлов на текстовые и прочие
* в получившийся location текстовых файлов добавим сжатие gzip
* так же добавим сжатие gzip в location динамического содержимого wordpress - это по идее тоже текстовое содержимое, которое должно эффективно сжиматься
* для статичного содержимого проставляем заголовки клиенского кэширования директивой
  ```
  expires max;
  ```
* для `favicon.ico` и страницы `robots.txt` настроим серверное кэширование (в реальных конфигурациях стоит предусмотреть размещение кэша вне контейнера)
* в головной части конфига - контексте http зададим расположение кэша и разместим сопутсвующие директивы
