# ДЗ урока № 6 — Обратный прокси (reverse proxy)

ДЗ будем делать используя WordPress в Docker

Набор файлов для запуска в каталоге `wp`.

Секреты определены через файл .env, который не опубликован в репозитории. Ожидаемое содержимое файла:
```
MYSQL_ROOT_PASSWORD=
MYSQL_USER=
MYSQL_PASSWORD=
```

`docker-compose.yml` - типовой от wordpress, с заменой nginx на angie

в конфиге angie (`angie-conf/http_angie.conf`) определим разные location:
* корень сайта
* динамическая часть wordpress, как proxy fastcgi_pass
* известные частозапрашиваемые файлы перечислим в отдельной отдельной combined location и отключим логирование их отсутсвия
* известные префиксы статичного содержимого перечислим в отдельной combined location и зададим максимальную продолжительность хранения
* регулярным выражением по расширению файлов картинок, стилей, скриптов, документов зададим таким файлам максимальную продолжительность хранения
